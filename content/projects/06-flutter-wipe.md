Rust CLI that recursively scans a directory tree for Flutter projects and runs
`flutter clean` in each to reclaim disk space — multi-threaded parallel
scanning and cleaning, a one-line installer, a short `fw` alias, and CI-built
release binaries for Linux, macOS and Windows. Because `build/` folders add
up fast.
