Rust CLI that crawls any documentation website and generates structured
SKILL.md files for LLM agents like Claude Code and Cursor: async polite
crawling with robots.txt support, smart content extraction that strips nav
and noise, token-optimized markdown output, an interactive setup wizard, and
cross-platform release binaries via CI.
