Two native iOS apps in **pure SwiftUI with MVVM**: an anime browser (Jikan API)
with debounced search, infinite scroll, and Core Data persistence; a movie app
(TMDB) with watchlist, translated pixel-perfect per Apple's Human Interface Guidelines.

Swift Concurrency networking, Combine-driven reactive binding, memory/disk image
caching, and API rate limiting for smooth scrolling on a low memory footprint.
